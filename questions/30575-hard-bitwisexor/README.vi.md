Triển khai ```BitwiseXOR<S1,S2>``` which takes two binary string literal type and returns a binary string that represents the bitwise XOR of S1 and S2

Ví dụ:

```typescript
BitwiseXOR<'0','1'> // expect '1'
BitwiseXOR<'1','1'> // expect '0'
BitwiseXOR<'10','1'>  // expect '11'
```
