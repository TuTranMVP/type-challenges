Triển khai hàm JavaScript `Array.includes` trong hệ thống type. Một type nhận hai đối số. Kết quả đầu ra phải là boolean `true` hoặc `false`.

Ví dụ:

```ts
type isPillarMen = Includes<['Kars', 'Esidisi', 'Wamuu', 'Santana'], 'Dio'> // kỳ vọng là `false`
```
