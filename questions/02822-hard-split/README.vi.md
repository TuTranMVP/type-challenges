The well known `split()` method splits a string into an array of substrings bởi looking for a separator, and returns the new array. The goal of this challenge is to split a string, bởi using a separator, but in the type system!

Ví dụ:

```ts
type result = Split<'Hi! How are you?', ' '>  // should be ['Hi!', 'How', 'are', 'you?']
```
