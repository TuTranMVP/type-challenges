Triển khai type `CheckRepeatedChars<T>` which will return whether type `T` contains duplicated member

Ví dụ:

```ts
type CheckRepeatedTuple<[1, 2, 3]>   // false
type CheckRepeatedTuple<[1, 2, 1]>   // true
```
