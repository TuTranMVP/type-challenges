The transpose of a matrix is an operator which flips a matrix over its diagonal; that is, it switches the row and column indices of the matrix A bởi producing another matrix, often denoted bởi A<sup>T</sup>.

```ts
type Matrix = Transpose <[[1]]>; // kỳ vọng to be [[1]]
type Matrix1 = Transpose <[[1, 2], [3, 4]]>; // kỳ vọng to be [[1, 3], [2, 4]]
type Matrix2 = Transpose <[[1, 2, 3], [4, 5, 6]]>; // kỳ vọng to be [[1, 4], [2, 5], [3, 6]]
```
