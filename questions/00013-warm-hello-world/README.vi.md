Xin chào, thế giới!

Trong Type Challenges, chúng ta sử dụng chính hệ thống type để thực hiện assertion (kiểm tra).

Với challenge này, bạn cần thay đổi đoạn code sau để các test cases pass (không có lỗi type check).

```ts
// kỳ vọng là kiểu string
type HelloWorld = any
```

```ts
// bạn cần làm cho đoạn này hoạt động
type test = Expect<Equal<HelloWorld, string>>
```

Click nút `Bắt đầu Challenge` để bắt đầu code! Chúc bạn code vui vẻ!
