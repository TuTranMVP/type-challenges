Triển khai `CapitalizeWords<T>` which converts the first letter of **each word of a string** to uppercase and leaves the rest as-is.

Ví dụ

```ts
type capitalized = CapitalizeWords<'hello world, my friends'> // kỳ vọng to be 'Hello World, My Friends'
```
