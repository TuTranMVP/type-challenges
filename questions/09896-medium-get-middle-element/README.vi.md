Get the middle element of the array bởi implementing a `GetMiddleElement` method, represented bởi an array

> If the length of the array is odd, return the middle element
> If the length of the array is even, return the middle two elements

Ví dụ

```ts
  type simple1 = GetMiddleElement<[1, 2, 3, 4, 5]>, // kỳ vọng to be [3]
  type simple2 = GetMiddleElement<[1, 2, 3, 4, 5, 6]> // kỳ vọng to be [3, 4]
```
