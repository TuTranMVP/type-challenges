Triển khai hàm JavaScript `Array.concat` trong hệ thống type. Một type nhận hai đối số. Kết quả đầu ra phải là một mảng mới bao gồm các inputs theo thứ tự từ trái sang phải.

Ví dụ:

```ts
type Result = Concat<[1], [2]> // kỳ vọng là [1, 2]
```
